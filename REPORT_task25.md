## 3. Описание нового интерфейса

**Композиция (сверху вниз):**

1. Заголовок «Proxy VPN» + меню.
2. **«Защищённое соединение»** — крупный заголовок.
3. Подзаголовок: **«Быстро. Просто. Без настроек.»**
4. Компактный **индикатор состояния** (точка/спиннер + текст).
5. **Две одинаковые круглые кнопки** (~112 dp) горизонтально:
   - **Тестирование** — иконка Refresh, холодный голубой, мягкая подсветка, спиннер при проверке;
   - **Подключиться / Отключиться** — **кастомная иконка питания** (без extended-icons), насыщенный синий; при подключении — «Отключиться»; спиннер при `Connecting`.
6. Результат теста / короткий статус.
7. Подпись: «Без ввода адресов и паролей — всё уже настроено».

**Палитра:** `#0C1728` фон, `#15283E` карточка, `#203A54` кнопка-тест, `#38BDF8`/`#7DD3FC` акценты, `#F0F7FF` текст, `#94AFCB` вторичный.

**Состояния индикатора:**

| Состояние | Отображение |
|---|---|
| Выключен | серый — «Не подключено» |
| Проверка | голубой — «Проверка» |
| Подключение | голубой — «Подключение» |
| Работает | зелёный — «Подключено» |
| Ошибка | красный — «Ошибка соединения» |

**Анимации:** scale 0.93 при нажатии, `animateColorAsState` фона/иконки, бесконечный spin/глow при busy/connected — лёгкие, без тяжёлых эффектов.

**Удалено:** `OutlinedTextField` (IP/порт/логин/пароль), RadioButton HTTP/HTTPS, «Сохранить», «Показать пароль», карточка «Ограничения» (техническая), `onSave`.

## 6. Поведение кнопок

### Тестирование
1. Берёт `ProxyEmbedded.config` → `ProxyTester.test`.
2. Анимация (спиннер), **не** запускает VPN.
3. Успех: **«Соединение доступно»** (+ `N мс`, если замерено).
4. Ошибка: **«Не удалось подключиться к серверу»**.
5. Технические ошибки/407/хосты пользователю **не показываются**.

### Подключиться / Отключиться
1. `VpnService.prepare` — при необходимости (Activity, без изменений).
2. `connect()` — guard: **нельзя** повторный start при `Connecting`/`Connected`.
3. `disconnect()` — только из `Connected`; остановка сервиса.
4. Статус из broadcast `ProxyVpnService` → UI; `STATUS_ERROR` → текст **«Ошибка соединения»** (сырые сообщения движка не выводятся).
5. `systemVpnActive` + `refreshSystemVpnStatus` — актуализация при возврате/статусе.
